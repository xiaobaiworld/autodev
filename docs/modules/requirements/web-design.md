# 网页工作台设计与本轮范围

> 2026-11-09 旧飞书桥适配层（`src/channels/`、`requirements.feishu`、`requirements.messaging`）与配对码功能已移除，见 D024；下文涉及它们的内容仅作历史证据，对应命令和接口已不存在。

> 2026-11-08 整合说明：本文件对应版本化兼容工作台（`requirements.versioned_session.SessionStore`），不作为默认统一网页、`ReqSessionStore` 或九章节 SRS 的契约。两套会话不自动同步；端口、launchd 与真实试用记录是当时证据，本次未复核运行服务。入口与边界见 [模块说明](README.md)。

2026-11-07，用户要求确认网页版能执行并优化网页设计。沿用现有需求后端和标准库网页，不引入框架、远程部署或新的业务流程。

桌面采用三个区域：左侧需求列表和搜索，中间需求交流，右侧当前需求文档。顶部显示梳理→独立审核→版本确认及当前待办；文档区可切换需求、审核、调用记录。正文用结构化草稿生成可读章节，不直接展示 Markdown 标记或英文缺项。当前版本可在网页明确确认、下载，并生成飞书配对码。手机收敛为纵向布局。

视觉：暖白背景、深绿主操作、轻分隔线；正文采用本机中文字体，避免联网字体或图片。会话状态、当前动作和确认条件比技术 ID 更突出。原文按纯文本 DOM 输出，不用 innerHTML；模型、轮次上限放在新建表单的可展开配置内。

本轮同时修正前端的会话切换与轮询：请求关联当前会话，旧请求不能覆盖新选择；失败保留输入，可重试；工作中刷新能继续显示后台状态。确认仍交后端检查版本/审核，不扩大权限。飞书配对复用已实现的 issue_pairing，本机同源 POST 与既有 CSRF 校验一致。

验收：已有 HTTP 安全与会话测试回归，新增网页配对端点测试；用无费用演示在浏览器实际新建/补充/审核/确认/下载/配对，检查桌面与 375 宽布局及控制台；真实服务接现有根目录和独立中台，浏览器只读检查连通性，不为了视觉验证额外调用收费模型。
