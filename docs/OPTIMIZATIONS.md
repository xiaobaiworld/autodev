# 流程优化记录

本分支从 F4 起点重做后续优化。每条记录说明改动、缘由、回退方式和实测证据；没有测量的数据标为未测。

## O006：Agent 崩溃立即交给步骤重试

- **改了什么**：`driver.runner.make_invoke` 默认不让 autoloop 自己重试失败的 Agent 进程；首次失败即取消中台轮次并返回给 Controller，由步骤重试机制派发新事件。
- **为什么**：确定性的进程崩溃继续等待中台指数退避会浪费时间，而且与流水线自己的步骤重试重复。
- **怎么回退**：调用 `make_invoke(hub, hub_retries=N)`，恢复允许中台重试 N 次。
- **怎么量**：使用 `tests/f5_crash.py crash` 观察中台尝试次数、事件 ID、总耗时和残留进程。
- **实际结果**：runner 单测 8 项通过，包含首次失败移交；真实中台耗时与残留进程场景待 F5 联机验证。
